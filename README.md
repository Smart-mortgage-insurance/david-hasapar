# דוד הספר – מערכת זימון תורים

אתר חי לקביעת תורים לספר דוד, עם פאנל ניהול ותשתית מוכנה לחיבור למערכת טלפונית (ימות המשיח).

## מה יש כאן

| קובץ | תיאור |
|------|--------|
| `index.html` | דף הלקוחות – בחירת יום → שעה → שם+טלפון → קביעת תור |
| `admin.html` | פאנל ניהול לספר (מוגן בסיסמה) |
| `js/store.js` | **הליבה** – כל הנתונים והלוגיקה (מניעת כפילויות, יצירת תורים של 10 דק') |
| `js/booking.js` | לוגיקת דף הלקוחות |
| `js/admin.js` | לוגיקת פאנל הניהול |
| `css/style.css` | עיצוב (RTL, מותאם נייד) |

## הגדרות ברירת מחדל
- שעות: **11:00–19:00**, ימים **ראשון–חמישי**
- כל תור **10 דקות** (48 תורים ליום)
- סיסמת ניהול ראשונית: **`1234`** (יש להחליף בטאב "הגדרות")

## מה הספר יכול לעשות בפאנל הניהול (`admin.html`)
1. **תורים** – לראות לפי יום כל תור: שם, טלפון, ומקור (אתר/טלפון), ולבטל.
2. **סגירות** – סגירת יום שלם, סגירה מוקדמת (חסימה משעה מסוימת), או חסימת טווח (הפסקה).
3. **הגדרות** – ימי עבודה, שעות פתיחה/סגירה, שם העסק, כמה ימים קדימה, והחלפת סיסמה.

## איפה שמורים הנתונים — מחובר לימות המשיח ✅

ל-`store.js` יש שני מנועים, והבחירה אוטומטית:

| מנוע | מתי | סנכרון |
|------|------|--------|
| **ימות המשיח** (חי) | כשקיים `js/config.local.js` עם `window.YEMOT_CONFIG` | כל המכשירים + הטלפון → מוח אחד |
| **localStorage** (בדיקה) | כשאין config | מקומי לדפדפן בלבד |

**איך זה עובד:** כל התורים נשמרים בקובץ JSON יחיד בימות — `ivr2:/david-booking.json` —
דרך ה-API (`GetTextFile` לקריאה, `UploadTextFile` לכתיבה). ה-API של ימות מחזיר `CORS: *`,
כך שהדפדפן פונה אליו ישירות, וזה זמין ברשת מסוננת (call2all ברשימה הלבנה).

**מוכח:** תור שנקבע בדפדפן נקרא מיד ממכשיר אחר → סנכרון אמיתי ומניעת כפילויות בין כולם.

### הגדרה
1. העתק `js/config.example.js` ל-`js/config.local.js`.
2. מלא `username` (מספר מערכת) ו-`password` (סיסמת ניהול).
3. `config.local.js` הוא **gitignored** — לא עולה לגיטהאב.

> ⚠️ **אבטחה:** במצב החי, פרטי ימות נמצאים ב-JS של הדף. באתר ציבורי הם ניתנים לקריאה.
> מומלץ לייעד סיסמה נפרדת למערכת הזו. לאבטחה מלאה — proxy בצד שרת (ראה "מערכת טלפונית").

## מערכת טלפונית (IVR) — השלב הבא
לזרימת טלפון חכמה (השמעת תורים פנויים + קביעה בחיוג) בונים פונקציית **serverless**
(למשל Cloudflare Worker – חינמי) שימות פונה אליה בזמן שיחה (`api_link`).
היא מריצה את לוגיקת התורים וקוראת/כותבת לאותו `david-booking.json`.
**נטפרי לא רלוונטי כאן** — שרתי ימות קוראים ל-URL, לא הלקוח — והטוקן נשאר מאובטח בצד השרת.
